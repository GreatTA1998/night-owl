# Night Owl

An owl that sleeps on the computer dock. Instead of being overly logical and saying "go to sleep", it makes us FEEL more at peace and want to actually sleep. During the day-time, it's a Japanese translation companion using shisa.ai

## How it works

As a native MacOS app, the Dock Tile (app logo) is an AppKit canvas, redrawn at 20fps with a visibly breathing owl and rising. It doesn't need to be a static image file it turns out.
